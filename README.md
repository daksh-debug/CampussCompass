# 🎓 Campus Compass

Campus Compass is a modern student productivity web application designed to simplify university life. It provides an all-in-one dashboard for managing attendance, assignments, timetables, campus navigation, events, and GPA tracking.

Built using **HTML, CSS, and JavaScript**, the project focuses on delivering a clean, responsive, and intuitive user experience without requiring a backend.

---

## ✨ Features

### 📊 Dashboard

* Personalized welcome screen
* Overall attendance overview
* Today's academic summary
* Quick analytics
* Upcoming assignments
* Global subject search

### 📚 Attendance Manager

* Add and manage subjects
* Track attended and total classes
* Calculate attendance percentage automatically
* View overall attendance statistics

### 📅 Timetable

* Weekly class schedule
* Organized day-wise timetable
* Easy-to-read interface

### 📝 Assignment Tracker

* Create assignments
* Mark assignments as completed
* View pending assignments
* Dashboard integration

### 🗺 Campus Map

* Interactive NSUT campus map
* Easy navigation around campus

### 🎉 Events

* Dedicated page for university events and activities

### 🎓 GPA Calculator

* Calculate and monitor academic performance

---

## 🛠 Technologies Used

* HTML5

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Campus-Compass.git
```

### Open the project

Simply open `index.html` in your browser, or use the VS Code **Live Server** extension for the best development experience.

---

## 💾 Data Storage

Campus Compass uses the browser's **Local Storage** to save user data such as:

* Subjects
* Attendance
* Assignments
* Timetable data

No external database or backend is required.
